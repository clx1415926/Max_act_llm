Abstract (摘要)
----------------------------------------------------------------------
【写作目的】用 150-250 词概括研究动机、方法、核心发现和意义。
【主要内容】
- 背景: Sun et al. (2024) 发现 LLM 中存在"巨大激活值"(Massive Activations)，
  即极少数激活值比其他大数个数量级，固定在少数特征维度，充当隐式 bias。
  但该研究仅覆盖 LLaMA2, Falcon, Mixtral, Phi 等较早模型。
- 本文贡献: 对 8 个模型系列 (Qwen2.5/3/3.5, Qwen2.5-VL, Gemma2/3, Ling-MoE,
  GPT-OSS)、24 个检查点进行系统性分析。
- 核心发现:
  (1) 巨大激活值在所有测试模型中普遍存在，但量级跨模型差异巨大 (113 至 696,320)
  (2) 同系列模型中激活值量级通常随参数规模增大而增长
  (3) MoE 架构和最新一代模型 (Qwen3.5) 显著抑制了巨大激活值
  (4) 训练数据量的增加会持续放大激活值量级 (Ling 5T→20T)
  (5) 不同架构系列在激活值模式上表现出本质差异

1. Introduction (引言)
----------------------------------------------------------------------
【写作目的】阐述研究动机、定义研究问题、概述贡献。
【主要内容】
1.1 研究背景
    - LLM 推理部署中量化、剪枝、KV-cache 压缩等技术均依赖对激活值分布的理解
    - Massive Activations 现象 (Sun et al., 2024): 极少数激活值量级比其他大 10万倍
    - 该现象对 INT8/INT4 量化造成严重挑战

1.2 研究动机与问题
    - Sun et al. 仅在 LLaMA2 (7B/13B/70B), Falcon-7B, Mixtral-8x7B, Phi-2,
      MPT-7B, OPT, GPT-2 等较早模型上验证
    - 新一代模型 (Qwen2.5/3/3.5, Gemma2/3) 采用了改进的架构设计，是否改变了
      激活值模式尚不清楚
    - 提出 5 个研究问题 (RQ):
      RQ1: 巨大激活值是否普遍存在于新一代不同架构中?
      RQ2: 同系列模型随参数规模增大，最大激活值如何变化?
      RQ3: 不同系列相近规模的模型，激活值模式有何异同?
      RQ4: MoE 架构的激活值特征与 Dense 架构有何不同?
      RQ5: 多模态 (VL) 模型与纯文本模型的激活值有何差异?

1.3 主要贡献 (3-4 条)
    - 首次对 8 个模型系列进行跨架构、跨规模的巨大激活值系统性对比
    - 揭示 MoE 架构天然抑制巨大激活值的特性
    - 发现 Qwen3.5 系列激活值量级下降 1-2 个数量级的代际演进趋势
    - 通过 Ling 多训练阶段数据，首次量化训练过程中激活值的演变规律

2. Related Work (相关工作)
----------------------------------------------------------------------
【写作目的】梳理已有研究，定位本文在文献中的位置。
【主要内容】
2.1 LLM 中的异常激活值
    - Outlier Features (Dettmers et al., 2022, LLM.int8()): 特定特征维度在
      所有 token 上都有较大值
    - Massive Activations (Sun et al., 2024): 少数 token 在少数维度上有极端值，
      与 Outlier Features 本质不同
    - 两者的区别: Outlier Features 是 feature-level, Massive Activations 是
      token×feature 交叉点

2.2 模型量化与激活值处理
    - SmoothQuant (Xiao et al., 2023): 通过数学变换平滑激活值分布
    - GPTQ, AWQ 等权重量化方法
    - 激活值异常对量化精度的影响

2.3 模型架构与训练
    - Dense vs MoE 架构差异
    - Normalization 策略 (LayerNorm, RMSNorm, Pre-Norm, Post-Norm)
    - Scaling Laws 视角下的模型行为分析

4. Existence of Massive Activations (巨大激活值的普遍性)
----------------------------------------------------------------------
对标参考论文 Section 2 "Existence of Massive Activations"

【写作目的】在可操作化的量化判据下, 验证巨大激活值在新一代模型中
            的普遍存在性, 并识别反例。本节定义一个在本文保存粒度下
            可严格计算、且对 Sun et al. (2024) 原始判据具有单侧数学
            保证的判据 (Definition C), 作为 Sun 严格判据的下界近似。

【参考: Sun et al. (2024) 的原始定义 (Definition S)】
    hidden state x ∈ R^d 中满足以下两条的标量激活 x_i 记为 massive:
    (S-i)  |x_i| > 100
    (S-ii) |x_i| / median_{j=1..d}(|x_j|) > 1000
    其中 median 是单个 hidden state 内 d 个元素绝对值的中位数 (element
    median)。这一判据要求 per-element 原始值, 无法仅从层级聚合统计
    (mean / abs_mean / std / rms / max / min) 恢复。

【本文采用: Definition C (peak-layer abs_mean 归一化)】
    设 ℓ* = argmax_ℓ ‖h_ℓ‖_∞ 为 hidden 全局峰值所在层, x* 为该层峰值
    标量, m_ℓ* = mean_j(|h_{ℓ*, j}|) 为该层元素绝对值均值 (abs_mean)。
    判据:
    (C-i)  |x*| > 100
    (C-ii) |x*| / m_ℓ* > 100

    两条阈值 (100, 100) 的选择理由见下方数学比较和鲁棒性检验。

【数学比较: Definition C 与 Sun 定义 S 的关系】
    命题 (单侧下界): 对任一 hidden state h ∈ R^d, 设 μ = mean(|h|) 为
    abs_mean, m = median(|h|) 为 element median, 且 |h| 的经验分布
    右偏 (heavy-tailed, 即高于均值的尾部比低于均值的尾部重)。则
          μ  ≥  m                                              (*)
    证明草图: 右偏分布 (非负随机变量, skewness > 0) 满足 mean ≥ median,
    这是二阶矩可积分布在右偏条件下的一般性质; 在 LLM hidden 中, 单个
    layer 的 |h| 分布由"大量接近 0 的元素 + 少量重尾元素"构成, 该条件
    经验普遍成立 (Sun et al. 亦在其 Fig.2 中展示此形态)。

    推论 (C 为 S 的下界近似):
    在峰值层 ℓ* 处,
          |x*| / μ_{ℓ*}   ≤   |x*| / m_{ℓ*}
    即 Definition C 的尖锐度比值 ≤ Sun 定义 S 的尖锐度比值。因此:
        C-ii (C 比值 > T_C)  ⟹  S-ii (S 比值 > T_C)
    只要 C 判"通过", S 必然在同一阈值下通过。换言之, C 是 S 的保守
    (偏紧) 判据: "C 通过" ⇒ "S 通过"; 反向不必然。

    阈值选择 T_C = 100 的理由:
    - Sun et al. 使用 T_S = 1000。由 (*), 一般 μ/m 比 ≈ 数倍到数十倍
      (由层分布重尾程度决定), 因此取 T_C = 100 作为 T_S = 1000 的保守
      下调, 既保留"尖锐度"语义, 又避免因 μ > m 造成的系统性低估。
    - 鲁棒性检验: 在 24 个模型上, T_C ∈ {100, 200} 给出完全一致的判定
      (23/24 通过, 仅 Qwen3.5-0.8B 不通过), 不存在边界敏感模型。

【为什么用 Definition C 而不用 Sun 的严格定义 S】
    (1) 数据粒度限制: 本文数据流水线仅保存各层级的聚合统计量 (mean,
        std, abs_mean, rms, max, min, count), per-element 原始激活未
        保存。S-ii 所需的 element median 在技术上不可直接计算。
    (2) 数学可证的单侧保证: 命题 (*) 保证 C 是 S 的下界近似, "C 通过"
        严格蕴含 "S 通过"。因此用 C 做存在性判定只会漏判, 不会误判,
        这是存在性声明所需的保守方向。
    (3) 局部性优于全局代理: 相比"跨层 abs_mean 中位数"代理 (需额外
        假设峰值层不是异常均匀层), Definition C 只使用峰值层本身的
        统计量, 不引入跨层相对性假设, 语义更干净。
    (4) 经验鲁棒: 在 24 模型上 T_C = 100 与 200 判定一致, 无边界案例;
        Sun 定义在 T_S = 1000 下代理判定存在 gemma-2-2b/9b 边界问题,
        C 无此问题。

4.2 结论
    (a) Definition C 下 23/24 模型存在 massive activations, 普遍性得到
        确认, 覆盖 Qwen2.5 / Qwen2.5-VL / Qwen3 / Qwen3.5 / Gemma2 /
        Gemma3 / Ling / GPT-OSS 全部 8 个家族。由 C ⇒ S 的数学保证,
        这 23 个模型在 Sun 原始定义下亦必然存在。
    (b) Qwen3.5-0.8B 是唯一明确的反例: hidden 峰值仅 23.25, 同时未破
        绝对阈值 (100) 和尖锐度阈值 (C 比 91, 远低于 100)。结合其
        同家族大模型 (9B / 27B / 35B-A3B) 均通过, 提示该家族在小规模
        下分布被整体扁平化, 是 "massive-free" 架构设计的候选样本。
        该反例不依赖判据选择 —— 在 Sun 严格判据下同样不通过。
    (c) 激活量级 ≠ 是否存在: Qwen3.5-9B (|x*|=956) 和 Qwen3.5-35B-A3B
        (|x*|=133) 的绝对值远小于典型 Dense 大模型, 但仍通过 C 判定,
        说明判据刻画的是"尖峰相对尖锐度", 与绝对量级是两个独立维度。

4.3 激活值的出现位置 (存在性层面, 仅作扼要陈述)
    - 通过判据 C 的 23 个模型, 全局最大值均位于 hidden state
      (判据本身即以 hidden state 为对象, 故这是同义确认)。
    - 少数模型 (Qwen3-8B, gpt-oss-20b) 在 mlp_output 亦达到同量级,
      但 hidden 侧仍满足 Definition C, 不影响判定。
    - 本节不展开"各组件量级分布 / 占比 / 逐层行为"和"符号-组件签名",
      分别交由 Section 5.4 (组件维度分析) 和 Section 7.2 (跨架构家族
      签名) 讨论。

4.4 与 Sun et al. (2024) 的对比
    - 判据层面: 本文因 per-element 原值未保存, 无法直接计算 Sun 的
      element-median, 改用 Definition C (peak-layer abs_mean 归一化);
      已在【数学比较】中证明 C 通过 ⇒ S 通过, 故本文"存在"结论对 Sun
      原始定义仍成立。
    - 观察层面: Sun et al. 在 LLaMA2-7B 等模型上观察到固定 feature dim
      (1415, 2533) 的集中现象, 本文因未保存 per-dimension 元素值, 无法
      复现该观察; 此为本文局限, 列入 Section 10.5。
    - Sun et al. 发现巨大激活值与起始 token、分隔符 token 关联, 本文
      关于 token-level 定位分析同样受限于保存粒度, 不展开。
    - 扩展贡献: 本文首次给出 Qwen3.5 / Gemma3 / Ling / GPT-OSS 等 2024-
      2025 年新模型在可量化判据下的存在性判定, 并识别出 Qwen3.5-0.8B
      这一明确反例 (在 C 与 S 两种定义下均不通过)。

5.3 涌现-保持-消退模式验证

    Sun et al. (2024) 的核心观察 (基于 LLaMA2, Phi-2):
    - 巨大激活值在初始层突然涌现
    - 在中间层保持为近似常数
    - 在最后几层开始消退

    本文对各模型的验证结果:

    符合原文模式的模型 (涌现-保持-消退):
    - Qwen2.5 全系列: layer_1-4 涌现, 中间层保持, layer_26-27 消退
    - Qwen3 Dense 模型: 类似模式
    - Ling 全系列: layer_1 极端涌现, 中间层保持, layer_20(post-norm) 消退
    - gpt-oss-20b: layer_1 涌现

    部分偏离的模型:
    - Gemma2/3: 涌现较为渐进 (2-3x 而非 100x), 且最后几层不消退反而
      持续增大 (Gemma2-27b 最后 3 层 abs_mean: 206→237→307)
    - Qwen3.5: 不符合"突然涌现"模式, 激活值渐进缓慢增长


5.4 各组件的逐层行为

    - attn_output: 通常最大值在首层或中间层, 量级远小于 hidden
    - mlp_output: 通常最大值与 hidden 的 spike 层一致
    - hidden: 残差累积效应, 决定了全局最大值的位置
    - embedding_output: 量级极小 (abs_mean < 1.3)
    - final_layernorm: 通常压缩, 但不完全移除离群值

    跨模型统计:
    - hidden state 作为全局最大值载体: 21/24 模型 (87.5%)
    - mlp_output 作为全局最大值载体: 2/24 (Qwen3-8B, gpt-oss-20b)
    - final_layernorm 作为全局最大值载体: 1/24 (Qwen3.5-0.8B, 特例)

    各组件的典型最大激活值范围 (跨 24 模型):
    - embedding_output: 0.3 - 63.75
    - attn_output:     46 - 3,632
    - mlp_output:      96 - 145,408
    - hidden:          23 - 696,320

7.2 符号-组件签名 (家族指纹)
    【核心观察】全局最大激活值的"符号 + 出现组件"组合在同家族内部
    高度一致, 构成家族级签名, 可作为架构指纹。
    【数据】(Table 2 全局最大值符号 + 出现位置)
    +-----------------+---------+-----------------------------------+
    | 家族            | 符号    | 出现组件                          |
    +-----------------+---------+-----------------------------------+
    | Qwen2.5         | 全负    | hidden (3/3)                      |
    | Qwen2.5-VL      | 混合    | hidden (3/3)                      |
    | Qwen3           | 全正    | hidden (3/4), mlp_output (1/4)    |
    | Qwen3.5         | 混合    | hidden (3/4), final_ln (1/4)      |
    | Gemma2 / 3      | 全正    | hidden (5/5)                      |
    | Ling            | 全负    | hidden (4/4)                      |
    | GPT-OSS         | 负      | mlp_output (1/1)                  |
    +-----------------+---------+-----------------------------------+
    【结论】
    - Qwen 系列符号从 2.5 (全负) → 3 (全正) → 3.5 (混合) 出现代际翻转,
      支持 "代际演进改变了放大机制" 的假设 (详见 Section 8)。
    - Gemma (全正) 与 Qwen2.5 / Ling / GPT-OSS (全负) 呈反向极性, 结合
      Gemma 家族量级最大的事实, 提示两组家族在初始化 / 归一化 / optimizer

    - 组件维度的跨模型占比统计 (hidden 21/24, mlp_output 2/24,
      final_layernorm 1/24) 归属 Section 5.4, 本节不重复。

7.3 规律: 家族身份 > 参数规模 (Family dominates Scale)
    【核心观察】同家族内部激活值跨度远小于跨家族同尺寸跨度。
    【数据】
    - 同家族总增长倍数 (Table 3): Qwen2.5 3.7x, Qwen3 2.4x, Gemma3 2.9x
      (0.8B~32B 范围内, 同家族最大比值 ≤16.2x, 且 Qwen3.5 为特例)
    - 跨家族同尺寸比值 (7.1): ~2B 级 125x, ~27B 级 378x
    【结论】
    - 激活值量级主要由架构家族决定, 规模只提供家族内部的次级调制。
    - 推论: 若要预测新模型激活值量级, 已知其家族比已知其参数量提供更多信息。
    - 量化 / 部署意义: 量化策略可按家族制定默认配置, 再按规模微调,
      无需对每个模型单独标定。

      Tier 4 (困难): GPT-OSS (145,408), Gemma2-27b (157,696)
      Tier 5 (极难): Gemma3 (239,616-696,320)
    - 建议: 对 Tier 4-5 模型使用 SmoothQuant 或混合精度方案

10.2 架构设计启示
    - MoE 架构天然抑制巨大激活值 → 对量化友好
    - Qwen3.5 的激活值降低暗示存在有效的架构/训练改进 (具体待公开)
    - Gemma3 的激活值恶化说明架构改进不一定改善激活值分布

10.3 训练策略的影响
    - Ling 数据: 训练越久激活值越大, 但增速递减
    - 与 Sun et al. 的 "implicit bias" 理论一致: 模型在训练过程中
      逐渐"学习"依赖巨大激活值作为隐式 bias

10.4 与 Sun et al. (2024) 的综合对比
    - 一致的发现: 普遍性、深度模式 (涌现-保持-消退)、hidden state 为主
    - 新的发现: 代际演进趋势、MoE 抑制效应、训练阶段影响
    - 不一致: Qwen3.5 不符合"突然涌现"模式, Gemma 末层不消退

10.5 局限性
    - 判据代理: 因 per-element 激活未保存, 无法直接计算 Sun et al.
      (2024) 的 element-median 比值, 本文改用 Definition C (peak-layer
      abs_mean 归一化, 见 Section 4)。C 具有 "C 通过 ⇒ S 通过" 的单侧
      数学保证, 但反向不蕴含 —— 故 "C 不通过" 不等价于 Sun 定义下"不
      存在"; 仅 Qwen3.5-0.8B 这一反例在两种判据下均不通过。
    - 未分析具体 feature dimension 和 token position (原文的核心分析之一)
    - 未做 intervention analysis 验证激活值功能 (原文 Section 3)
    - 未分析 attention pattern 的变化 (原文 Section 4)
    - VL vs 文本模型对比存在 Instruct vs Base 混淆因素
    - Gemma3 为 Instruct 版本, 缺少 Base 对照

----------------------------------------------------------------------
11. Conclusion (结论)
----------------------------------------------------------------------
【写作目的】总结核心发现和意义。
【主要内容】
- 巨大激活值是 LLM 的普遍现象, 跨 8 个系列均存在
- 量级差异可达 6,000 倍 (113 vs 696,320)
- 3 个关键影响因素: 架构类型 (MoE vs Dense), 代际设计演进, 训练数据量
- MoE 和 Qwen3.5 代表了抑制巨大激活值的有效方向
- 为模型量化选型和架构设计提供了实证依据
- 未来工作: feature dimension 分析, intervention 实验, 训练动态追踪
