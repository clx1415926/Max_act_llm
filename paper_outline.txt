Abstract (摘要)
----------------------------------------------------------------------
【写作目的】用 150-250 词概括研究动机、方法、核心发现和意义。
【主要内容】
- 背景: Sun et al. (2024) 发现 LLM 中存在"巨大激活值"(Massive Activations)，
  即极少数激活值比其他大数个数量级，固定在少数特征维度，充当隐式 bias。
  但该研究仅覆盖 LLaMA2, Falcon, Mixtral, Phi 等较早模型。
- 本文贡献: 对 8 个模型系列 (Qwen2.5/3/3.5, Qwen2.5-VL, Gemma2/3, Ling-MoE,
  GPT-OSS)、24 个检查点进行系统性分析。
- 核心发现:
  (1) 巨大激活值在新一代模型中广泛但非普遍存在 (Sun 判据下 20/24 通过);
      量级跨模型差异巨大 (122 至 696,320)
  (2) 同系列模型中激活值量级通常随参数规模增大而增长 (但 Gemma2 存在
      尺寸低谷反例)
  (3) MoE 架构和最新一代模型 (Qwen3.5) 显著抑制了巨大激活值, Qwen3.5 家族
      4 个模型中 3 个在 Sun 判据下不通过
  (4) 训练数据量的增加会持续放大激活值量级 (Ling 5T→20T, |x*| +54%)
  (5) 不同架构系列在激活值模式上表现出本质差异

1. Introduction (引言)
----------------------------------------------------------------------
【写作目的】阐述研究动机、定义研究问题、概述贡献。
【主要内容】
1.1 研究背景
    - LLM 推理部署中量化、剪枝、KV-cache 压缩等技术均依赖对激活值分布的理解
    - Massive Activations 现象 (Sun et al., 2024): 极少数激活值量级比其他大 10万倍
    - 该现象对 INT8/INT4 量化造成严重挑战

1.2 研究动机与问题
    - Sun et al. 仅在 LLaMA2 (7B/13B/70B), Falcon-7B, Mixtral-8x7B, Phi-2,
      MPT-7B, OPT, GPT-2 等较早模型上验证
    - 新一代模型 (Qwen2.5/3/3.5, Gemma2/3) 采用了改进的架构设计，是否改变了
      激活值模式尚不清楚
    - 提出 5 个研究问题 (RQ):
      RQ1: 巨大激活值是否普遍存在于新一代不同架构中?
      RQ2: 同系列模型随参数规模增大，最大激活值如何变化?
      RQ3: 不同系列相近规模的模型，激活值模式有何异同?
      RQ4: MoE 架构的激活值特征与 Dense 架构有何不同?
      RQ5: 多模态 (VL) 模型与纯文本模型的激活值有何差异?

1.3 主要贡献 (3-4 条)
    - 首次对 8 个模型系列进行跨架构、跨规模的巨大激活值系统性对比
    - 揭示 MoE 架构天然抑制巨大激活值的特性
    - 发现 Qwen3.5 系列激活值量级下降 1-2 个数量级的代际演进趋势
    - 通过 Ling 多训练阶段数据，首次量化训练过程中激活值的演变规律

2. Related Work (相关工作)
----------------------------------------------------------------------
【写作目的】梳理已有研究，定位本文在文献中的位置。
【主要内容】
2.1 LLM 中的异常激活值
    - Outlier Features (Dettmers et al., 2022, LLM.int8()): 特定特征维度在
      所有 token 上都有较大值
    - Massive Activations (Sun et al., 2024): 少数 token 在少数维度上有极端值，
      与 Outlier Features 本质不同
    - 两者的区别: Outlier Features 是 feature-level, Massive Activations 是
      token×feature 交叉点

2.2 模型量化与激活值处理
    - SmoothQuant (Xiao et al., 2023): 通过数学变换平滑激活值分布
    - GPTQ, AWQ 等权重量化方法
    - 激活值异常对量化精度的影响

2.3 模型架构与训练
    - Dense vs MoE 架构差异
    - Normalization 策略 (LayerNorm, RMSNorm, Pre-Norm, Post-Norm)
    - Scaling Laws 视角下的模型行为分析

    (c) 特殊架构: MoE (Ling 5T/10T/15T/20T, Qwen3-30B-A3B, Qwen3.5-35B-A3B),

3.2 评估数据集与流程
    - 每个模型系列使用对应的多样化评估数据集 (eval_diverse_5k_*.jsonl)
    - 样本数: 5000 (所有模型系列一致)
    - max_seq_len = 32768
    - 前向推理收集所有层的激活值统计

3.3 统计指标
    - 逐层统计: mean, std, abs_mean, rms, max, min, count
    - Top-5 极端激活值: 绝对值 Top5 和带符号 Top5
    - 全局最大激活值及其出现位置 (global_max_activation, global_max_location)
    - Sun 判据字段 (v2 新增): sun_peak_abs / sun_peak_token_median /
      sun_max_ratio_median / sun_n_pass (per-layer 通过 Sun 判据的 token 数)
    - 监测的层内组件 (6 类):
      * embedding_output: 词嵌入输出
      * layer_N_attn_output: 多头注意力输出
      * layer_N_mlp_gate: MLP 门控激活 (SwiGLU)
      * layer_N_mlp_output: MLP/前馈网络输出
      * layer_N_hidden: 完整隐藏状态 (残差连接后)
      * final_layernorm: 最终层归一化输出
    - MoE 模型额外监测: moe_gate, router_logits
    - 定义"涌现层"(Emergence Layer, 本文新定义): 最大激活值绝对值相对前一层
      跳变超过 10x 的层。Sun et al. 原文仅有 "suddenly emerge" 的定性描述,
      未给出阈值; 本文将其操作化为可计算判据, 便于 §5.2 的分类与 §9.2 的
      训练阶段趋势量化。

4. Existence of Massive Activations (巨大激活值的普遍性)
----------------------------------------------------------------------
对标参考论文 Section 2 "Existence of Massive Activations"

【写作目的】在可操作化的量化判据下, 验证巨大激活值在新一代模型中
            的普遍存在性, 并识别反例。v2 数据新增 Sun 原始判据字段
            (sun_n_pass), 可直接用 Sun 判据判定; Definition C 保留
            作为辅助判据 (两者互为交叉验证)。

【Sun et al. (2024) 原始定义 (Definition S)】
    hidden state x ∈ R^d 中满足以下两条的标量激活 x_i 记为 massive:
    (S-i)  |x_i| > 100
    (S-ii) |x_i| / median_{j=1..d}(|x_j|) > 1000
    其中 median 是单个 hidden state 内 d 个元素绝对值的中位数 (element
    median)。v2 数据流水线已保存每层 `sun_n_pass` (该层中通过 Sun 判据
    的 token 数, 即 x 中有元素满足两条件的 token 数) 与 `sun_max_ratio_
    median`, 故 Sun 判据可直接计算。

【判定口径】
    模型级: 任一 hidden 层存在 sun_n_pass ≥ 1 即算 "存在 massive activation"。

【辅助判据: Definition C (peak-layer abs_mean 归一化)】
    (C-i)  |x*| > 100
    (C-ii) |x*| / m_{ℓ*} > 100  (m_{ℓ*} 为峰值层 abs_mean)
    数学上 C-ii 严于 S-ii 在同阈值下的对应项, 即 "C 通过 ⇒ S 通过"
    (证明同 v1, 已验证)。C 在 v2 中作为第二意见.

【主要内容】

4.1 判定结果 (24 个模型, 双判据)

    Sun 判据依赖保存字段, 结果确定性。

4.2 结论
    (a) Sun 原始判据下 20/24 模型存在 massive activations; Definition C
        下 23/24 通过。覆盖 Qwen2.5 / Qwen2.5-VL / Qwen3 / Qwen3.5 /
        Gemma2 / Gemma3 / Ling / GPT-OSS 全部 8 个家族. 由 C ⇒ S 的
        数学保证, 23/24 C 通过模型中 20 个 S 也通过; 剩 3 个 (Qwen2.5-
        1.5B / Qwen3.5-9B / Qwen3.5-35B-A3B) "C 通过但 S 不通过",
        说明两判据有交叉验证价值.
    (b) 4 个 Sun 不通过模型中, Qwen3.5 家族占 3 个, 表明该家族在架构上
        系统性压制了"尖锐度"的极值. Qwen3.5-0.8B 同时在 C 与 S 下不通
        过, 是最干净的 "massive-free" 反例.
    (c) 激活量级 ≠ 是否存在: Qwen2.5-1.5B |x*|=7968 量级大, 但 Sun 比不
        过 (element-median 不够小); Qwen3.5-27B |x*|=1848 量级小, 但
        Sun 通过. 两个维度正交.

4.3 激活值的出现位置 (存在性层面, 仅作扼要陈述)
    - 通过判据 C 的 23 个模型中 22 个全局最大值位于 hidden state.
    - 反例: gpt-oss-20b 全局最大在 layer_23 mlp_output (|x*|=145,408);
      Qwen3.5-0.8B 全局最大在 final_layernorm (|x*|=122).
    - v1 中 "Qwen3-8B 全局最大在 mlp_output" 已不成立 —— v2 数据显示
      Qwen3-8B 全局最大 = 17,664 @ layer_16 hidden (已人工复核 JSON).
    - 本节不展开"各组件量级分布 / 占比 / 逐层行为"和"组件载体 / 符号倾向",
      分别交由 Section 5.4 (组件维度分析) 和 Section 7.2 (跨架构家族
      签名) 讨论。

4.4 与 Sun et al. (2024) 的对比
    - 判据层面: v2 数据已保存 Sun 判据字段, 可直接计算. 结果 20/24 通过,
      与 v1 用 Definition C 代理得到的 23/24 通过在普遍性结论上一致,
      但细粒度上 Sun 严于 C (Qwen3.5 家族有 3 个模型 C 通过但 Sun 不通过).
    - 观察层面: Sun et al. 在 LLaMA2-7B 等模型上观察到固定 feature dim
      (1415, 2533) 的集中现象. 本文 per-dimension 元素值仍未保存, 无法
      复现该观察; 此为本文局限, 列入 Section 10.5.
    - Sun et al. 发现巨大激活值与起始 token、分隔符 token 关联, 本文
      关于 token-level 定位分析同样受限于保存粒度, 不展开.
    - 扩展贡献: 本文首次给出 Qwen3.5 / Gemma3 / Ling / GPT-OSS 等 2024-
      2025 年新模型在 Sun 原始判据与 Definition C 两种判据下的双重
      判定, 并识别出整个 Qwen3.5 家族作为系统性反例家族.

4.5 Top-5 结构分析 (24 个模型全部扫描)

    【写作目的】在 top1 (global max) 之外利用已保存的 top5 (绝对值前 5,
                带符号和不带符号两种) 提供结构性观察, 补强家族指纹与
                "尖峰非孤立点"的经验证据, 并识别潜在 bf16 数值饱和案例。

    【扫描指标】
    - saturation: top5 绝对值是否完全相同
    - concentration: top1_abs / mean(top5_abs)
    - decay5/1: top5_abs / top1_abs
    - sign consistency: top5 带符号是否全同号
    - localization: |top5| ≥ 0.9·|top1| 的层数 (n_hot_layers)

    4.5.1 符号一致性 (区分 "模型内 top5 同号" 与 "家族内跨模型同号")
        【模型内部】24/24 模型的 top5 带符号全部同号。
        这是 "单个模型的尖峰非孤立点" 的强证据, 支持 §4.5.2 的集中度观察。
        【家族内跨模型】按各模型 top1 符号统计:
          同号家族:
            Ling         4/4 全负
            Qwen3        4/4 全正
            Gemma3       2/2 全正   (分代统计, 不合并)
          混合家族:
            Qwen2.5      2 负 + 1 正  (1.5B/7B 负, 32B 正)
            Qwen2.5-VL   2 负 + 1 正  (3B/7B 负, 32B 正)
            Qwen3.5      1 负 + 3 正  (0.8B 负 —— 但 Qwen3.5-0.8B 峰值
                         在 final_ln, 符号可比性较弱)
            Gemma2       1 负 + 2 正  (2b 负, 9b/27b 正)
          样本不足:
            GPT-OSS      n=1, 仅作个案 (负/mlp_out)
        家族级符号一致性的结论应仅限于 Ling / Qwen3 / Gemma3 三个
        同号家族, 不能泛化到 Qwen 系列整体. (v1 将 Gemma2/Gemma3 合并为
        同号已修正.)

    4.5.2 尖峰集中度 (支持 Sun "少数 token × 少数 dim")
        24/24 模型: top1/top5_mean ≈ 1.0, decay5/1 ≈ 1.0
        全部模型的 top5 都是一簇几乎相等的大值, 没有"孤立单点"情况,
        与 Sun et al. (2024) 对 Massive Activation 的描述一致:
        "少数 token 在少数 dim 上同时取到相近极端值"。

    4.5.3 多层传播 (新观察)
        定义 n_hot_layers = 满足 layer 内 top1_abs ≥ 0.9·global_top1_abs
        的层数。
        统计: 23/24 模型 n_hot_layers ≥ 2
              1/24  模型 n_hot_layers = 1 (Qwen3.5-0.8B, 也是 Sun 不过的)
        含义: 一旦 massive activation 形成, 沿残差流在多层间持续保持
              同量级, 不是单层瞬态。此观察在 Sun et al. 文献中未
              明确量化, 属本文新增。

    4.5.4 Top-5 完全相同的模型与 bf16 饱和讨论
        v2 数据下 Top5 绝对值完全相同的模型子集需重新统计 (部分 v1
        列表数值已变化, 如 Qwen3-8B 16384→17664, Qwen2.5-7B 12800→13248).
        v1 中 16384=2^14 这一"可疑 clipping"案例在 v2 不再成立.
        Gemma3-27b-it 696320 仍保持 top5 完全相同, 可能存在训练时激活
        规范化饱和.

        【关键说明】bf16 在 |x| ~ 10^4 处相邻浮点间隔约 32, 在 |x| ~ 10^5
        处约 1024, 因此 "top5 完全相同" 并不能直接推出数值 clipping。

        本文将饱和检测放入 limitations (§10.5), 不作为主要结论。

    【对论文结构的影响】
    - §7.2 组件载体 / §7.3 符号倾向 的证据基础由 top1 扩展到 top5, 但符号
      指标在 "模型内部 top5 同号" (强, 25/25) 与 "家族内跨模型同号" (弱,
      仅 3 家族) 两个粒度上分开陈述, 引用 §4.5.1
    - §10.5 limitation 增加一句: bf16 分辨率限制, 多个模型 top5 完全
      相同是否意味着数值饱和需要 fp32 复算, 列入 future work

    - 在最后几层开始消退

    符合原文模式的模型 (涌现-保持-消退):
    - Qwen2.5 全系列: layer_1-4 涌现, 中间层保持, layer_26-27 消退
    - Qwen3 Dense 模型: 类似模式
    - Ling 全系列: layer_1 极端涌现, 中间层保持, layer_20(post-norm) 消退

    - Qwen3.5: 不符合"突然涌现"模式, 激活值渐进缓慢增长


5.4 各组件的逐层行为

    - attn_output: 通常最大值在首层或中间层, 量级远小于 hidden
    - mlp_output: 通常最大值与 hidden 的 spike 层一致, 多数模型 mlp_out
      峰值接近 hidden 峰值 95-99% (组件共振)
    - hidden: 残差累积效应, 决定了全局最大值的位置
    - embedding_output: 量级极小 (abs_mean < 1.3)
    - final_layernorm: 通常压缩, 但不完全移除离群值

    跨模型统计 (v2, 24 个模型):
    - hidden state 作为全局最大值载体: 22/24 (91.7%)

      点, 但样本仍属 "观察性" 而非 "强证据"。
    【修正先前口径】
    - 删除 "Qwen2.5 全负" 的说法 (32B 为 +30,848, 实为混合, 负数集中
      在 ≤7B).
    - 删除 "Qwen 代际符号翻转 (负→正→混合)" 的表述, 替换为
      "只有 Qwen3 一代符号一致, 其余两代为混合"。
    - 删除 Gemma2+3 合并计作 "5/5" 的写法, 分代统计. Gemma2 为混合,
      Gemma3 为全正.

7.4 家族身份 > 参数规模 (中-强证据)
    【核心观察】同家族内部激活值跨度远小于跨家族同尺寸跨度。
    【数据】
    - 同家族跨尺寸 (Table 3):
        普通 Dense 家族 ≤5.6x (Qwen3 2.5x, Qwen2.5-VL 5.6x, Gemma3 2.8x,
        Qwen2.5 3.9x);
        Qwen3.5 家族 15.1x, 为极值, 主要由其起点异常低 (122) 拉高比值;
        Gemma2 家族非单调 (2B→9B 反降), 不纳入 "跨度" 统计。
    - 跨家族同尺寸 (7.1): ~2B 级 117x, ~8B 级 18x, ~27-32B 级 377x。
    【结论】
    - 家族差异 >> 规模差异: 跨家族同尺寸 (>100x) 远大于同家族跨尺寸
      (普通家族 ≤6x, 异类 ≤15x)。
    - 推论: 预测一个新模型的激活值量级时, 已知其家族比已知其参数量提供
      更多信息。
    - 量化 / 部署意义: 量化策略可按家族制定默认档 (见 §10.1 的 T1-T5
      分层), 再按规模微调, 不必对每个 checkpoint 单独标定。

8. Generational Evolution (代际演进分析)
----------------------------------------------------------------------
【写作目的】分析同一厂商不同代模型的激活值变化趋势。
【主要内容】

8.1 Qwen 系列演进: Qwen2.5 → Qwen3 → Qwen3.5

    小模型 (~1-2B):
    Qwen2.5-1.5B (7,968) → Qwen3-1.7B (14,208, +78%) → Qwen3.5-0.8B (122, -99.1%)

    中模型 (~8B):
    Qwen2.5-7B (13,248) → Qwen3-8B (17,664, +33%) → Qwen3.5-9B (956, -94.6%)

    大模型 (~27-32B):
    Qwen2.5-32B (30,848) → Qwen3-32B (35,328, +15%) → Qwen3.5-27B (1,848, -94.8%)

    关键发现:
    - Qwen2.5 → Qwen3: 激活值略有增大 (15%-78%)
    - Qwen3 → Qwen3.5: 激活值剧烈下降 1-2 个数量级 (94%-99%)
    - Qwen3.5 的涌现模式也从"突然涌现"变为"渐进增长" (详见 5.2)
    - Qwen3.5 在 Sun 判据下 3/4 不通过, 是唯一家族级反例

8.2 Gemma 系列演进: Gemma2 → Gemma3

    4B 级:
    Gemma2-2b (2,992) → Gemma3-4b-it (245,760, +8,115%)

    27B 级:
    Gemma2-27b (157,696) → Gemma3-27b-it (696,320, +341%)

    关键发现:
    - 与 Qwen 的演进趋势相反: Gemma3 激活值大幅增长
    - Gemma3-27b 的 top5 全部相同 (696,320), 可能存在数值饱和
    - 注: Gemma3 为 Instruct 版本, 存在 Base vs Instruct 混淆因素

9. Special Architecture Analysis (特殊架构分析)
----------------------------------------------------------------------
【写作目的】深入分析 MoE、训练阶段、多模态等特殊维度。
【主要内容】

9.1 MoE vs Dense 架构

    直接对比 (相同系列, 相近总参数):
    +------------------------+----------+-------------------+
    | 模型                   | 架构     | 全局最大激活值    |
    +------------------------+----------+-------------------+
    | Qwen3-32B              | Dense    | 35,328            |
    | Qwen3-30B-A3B          | MoE      |  1,512            |
    +------------------------+----------+-------------------+
    → MoE 仅为 Dense 的 4.3%

    +------------------------+----------+-------------------+
    | Qwen3.5-27B            | Dense    |  1,848            |
    | Qwen3.5-35B-A3B        | MoE      |    132            |
    +------------------------+----------+-------------------+
    → MoE 仅为 Dense 的 7.1%

    关键发现:
    - MoE 架构 consistently 抑制巨大激活值 (10-25 倍抑制)
    - MoE 的 moe_gate 最大值在 255 左右 (Ling 模型), router_logits < 27
    - 注: Qwen3-30B-A3B 峰值层出现在 layer_3 (深度 6.4%),
      可能存在 "MoE 提前涌现再被压回"的模式, 与 Dense 中后期峰值不同

9.2 训练过程的影响 (Ling 系列)

    Ling-mini-base-2.0 在不同预训练阶段 (v2 数据):
    +-------------------+-------------------+-----------+-----------+
    | 预训练数据量      | 全局最大激活值    | 出现层    | 涌现跳变  |
    +-------------------+-------------------+-----------+-----------+
    | 5T tokens         | 7,648             | layer_14  | 27.0x     |
    | 10T tokens        | 9,024 (+18.0%)    | layer_10  | 13.7x     |
    | 15T tokens        | 10,112 (+12.1%)   | layer_19  | 73.8x     |
    | 20T tokens        | 11,776 (+16.4%)   | layer_19  | 92.4x     |
    +-------------------+-------------------+-----------+-----------+

    关键发现:
    - 激活值量级随训练数据量单调增长 (5T→20T: +54.0%)
    - 增长率非单调递减 (18% → 12% → 16%)
    - 涌现的剧烈程度: 5T→10T 先降 (27→14x), 再升至 20T 的 92x,
      整体呈 U 形后单调上升, 与 v1 "177→894x 单调递增" 不一致, 已修正
    - 峰值位置随训练推移由 layer_14 → layer_10 → layer_19 → layer_19
      向末层漂移

9.3 视觉语言模型 vs 纯文本模型

    Qwen2.5-VL vs Qwen2.5 (纯文本, 同规模配对):
    +------------------------+----------+-------------------+
    | 模型                   | 类型     | 全局最大激活值    |
    +------------------------+----------+-------------------+
    | Qwen2.5-7B             | 文本     | 13,248            |
    | Qwen2.5-VL-7B          | VL       | 8,256             |
    +------------------------+----------+-------------------+
    | Qwen2.5-32B            | 文本     | 30,848            |
    | Qwen2.5-VL-32B         | VL       | 22,144            |
    +------------------------+----------+-------------------+

    关键发现:
    - 在 7B/32B 段, VL 低于同规模纯文本 (降低 28-38%)
    - 注: VL 模型为 Instruct 版本, 纯文本含 Base 与 Instruct 不完全配对,
      混淆因素仍存

9.4 GPT-OSS-20B 分析

    - 全局最大值: -145,408 @ layer_23_mlp_output
    - 唯一一个全局最大值出现在 mlp_output 而非 hidden 的大模型 (v1 曾
      把 Qwen3-8B 也列入, v2 已修正)
    - 激活值量级异常 (同规模 Qwen/Gemma 模型在 1万-3万量级)
    - Top5 全部为负值且相同 (-145,408)
    - 这是 24 个模型中唯一 "hidden 峰值不是全局峰值" 的情形 —— mlp_out
      在末层把输出放大到超过 hidden 残差流. 可能与其 expert 聚合机制或
      输出前 normalization 结构有关 (待验证).

10. Discussion (讨论)
----------------------------------------------------------------------
【写作目的】解释实验发现的含义和潜在影响。
【主要内容】
10.1 对模型量化与推理部署的启示
    - 量化友好度排序 (激活值越小越友好):
      Tier 1 (极佳): Qwen3.5 (122-1,848), MoE 模型 (132-1,512)
      Tier 2 (良好): Gemma2 小模型 (1,664-2,992)
      Tier 3 (中等): Qwen2.5 (7,968-30,848), Qwen3 Dense (14,208-35,328)
      Tier 4 (困难): GPT-OSS (145,408), Gemma2-27b (157,696)
      Tier 5 (极难): Gemma3 (245,760-696,320)
    - 建议: 对 Tier 4-5 模型使用 SmoothQuant 或混合精度方案

10.2 架构设计启示
    - MoE 架构天然抑制巨大激活值 → 对量化友好
    - Qwen3.5 的激活值降低暗示存在有效的架构/训练改进 (具体待公开);
      该家族 3/4 在 Sun 判据下不通过, 是当前唯一 "massive-free 倾向" 家族
    - Gemma3 的激活值恶化说明架构改进不一定改善激活值分布

10.3 训练策略的影响
    - Ling 数据: 训练越久激活值越大 (+54% 5T→20T), 但增长率非严格
      递减 (18%→12%→16%)
    - 与 Sun et al. 的 "implicit bias" 理论一致: 模型在训练过程中
      逐渐"学习"依赖巨大激活值作为隐式 bias

10.4 与 Sun et al. (2024) 的综合对比
    - 一致的发现: 普遍性 (Sun 判据 20/24)、深度模式 (涌现-保持-消退)、
      hidden state 为主 (22/24)
    - 新的发现: 代际演进趋势 (Qwen 抑制 vs Gemma 放大)、MoE 抑制效应
      (~5-7%)、训练阶段影响 (Ling +54%)、Qwen3.5 家族级反例
    - 不一致: Qwen3.5 不符合"突然涌现"模式, Gemma 末层不消退

10.5 局限性
    - 判据: v2 已直接计算 Sun 判据, 但 per-element 激活仍未保存,
      无法分析具体 feature dim 定位 (Sun et al. 的核心分析之一),
      也无法复现固定 dim 集中的结论
    - 未做 intervention analysis 验证激活值功能 (原文 Section 3)
    - 未分析 attention pattern 的变化 (原文 Section 4)
    - VL vs 文本模型对比存在 Instruct vs Base 混淆因素
    - Gemma3 为 Instruct 版本, 缺少 Base 对照
    - bf16 数值分辨率: 多个模型 top5 绝对值完全相同 (见 §4.5.4), 但
      bf16 在 |x|~10^4 处相邻浮点差 ≥ 16, 无法仅凭此判定训练/推理
      clipping, 需 fp32 复算方可区分 "bf16 同 bin" 与 "真正饱和",
      列入 future work。

----------------------------------------------------------------------
11. Conclusion (结论)
----------------------------------------------------------------------
【写作目的】总结核心发现和意义。
【主要内容】
- 巨大激活值是 LLM 的广泛现象, 跨 8 个系列 20/24 checkpoint 通过 Sun 判据
- 量级差异可达 5,700 倍 (122 vs 696,320)
- 4 个关键影响因素: 架构类型 (MoE vs Dense), 代际设计演进, 训练数据量,
  家族 normalization 设计
- MoE 和 Qwen3.5 代表了抑制巨大激活值的有效方向 (Qwen3.5 家族是目前
  唯一的"massive-free 倾向"家族)
- Gemma 代际反例警示: 架构改进方向不一定降激活
- 未来工作: feature dimension 分析, intervention 实验, 训练动态追踪
