跨架构 LLM 最大激活值分析 —— 简要大纲 (v2)
=========================================

基础信息
  - 参考: Sun et al., Massive Activations in LLMs, COLM 2024
  - 覆盖: 8 系列 / 24 checkpoint / 0.8B–35B
  - 数据: eval_diverse_5k_*.jsonl, 5000 样本, max_seq_len=32768
  - 判据: 直接用 Sun 原始定义 (新数据已含 sun_n_pass)
  - 范围: §1–§9.4 与 §10–§11 分母均为 24 个 Base 模型;
          3 个 Qwen2.5-Instruct 仅在 §9.5 使用.

研究问题
  RQ1 massive activation 在新一代模型中是否仍普遍 
  RQ2 同系列内激活值随尺寸的变化
     RQ3 跨系列同尺寸的差异幅度 
  RQ4 MoE vs Dense
  RQ5 VL vs 纯文本
  RQ6 训练步数的影响 
  RQ7 Instruct SFT 的影响 
  RQ8 层间分布规律


1. Introduction
   动机: 量化/剪枝/KV-cache 都依赖激活值分布.
   Sun 原文只覆盖 LLaMA2/Falcon/Mixtral.
   贡献: 对 Qwen2.5/3/3.5、Gemma2/3、Ling(5T–20T)、GPT-OSS、Qwen2.5-VL 做系统扫描.


2. Related Work
   - Outlier features (feature-level) vs massive activations (token×dim)
   - 量化: SmoothQuant / GPTQ / AWQ
   - 架构背景: Dense/MoE, Pre/Post Norm, RMS/LN


3. Methodology
   3.1 模型: 同系列、跨系列同尺寸、特殊架构 (MoE/VL/GPT-OSS)
   3.2 流程: 前向推理 + 逐层 hook
   3.3 指标:
       基本: mean/std/abs_mean/rms/max/min + top5 + 全局 max 位置
       Sun 字段: sun_peak_abs / sun_peak_token_median /
                sun_max_ratio_median / sun_n_pass
       组件: embedding / attn_out / mlp_gate / mlp_out / hidden / final_ln
       MoE 额外: moe_gate, router_logits
       跳变层: 相邻层 |max| 跳变 ≥ 10×


4. massive activation存在性 (Sun 原始判据)
   4.1 判据: |x|>100 且 |x|/element_median>1000;
       模型级: 任一 hidden 层 sun_n_pass ≥ 1 即通过.

   4.2 结果: 20/24 通过.
       4 个反例:
         Qwen2.5-1.5B     |x*|=7968, element-median 不够小
         Qwen3.5-0.8B     |x*|=122  (final_ln)
         Qwen3.5-9B       |x*|=956
         Qwen3.5-35B-A3B  |x*|=132  (MoE)

   4.3 载体: 22/24 在 hidden; gpt-oss-20b 在 mlp_out; Qwen3.5-0.8B 在 final_ln.


5. 层间分布
   核心发现: 峰值深度无明显规律, 但层间演化呈现两种分布模式.

   5.1 峰值相对深度 — 无规律
       Qwen2.5     1.5B→7B→32B    18%, 44%, 98%
       Qwen2.5-VL  3B→7B→32B      91%, 93%, 69%
       Qwen3       1.7B→8B→32B    93%, 46%, 69%;  30B-A3B 6%
       Qwen3.5     0.8B→9B→27B    100% (全尾层);  35B-A3B 98%
       Gemma2      2b→9b→27b      94%, 100%, 84%
       Gemma3      4b→27b         88%, 75%
       Ling        5T/10T/15T/20T 70%, 50%, 95%, 95%
       GPT-OSS-20B                96%
       → 跨 6% – 100%, 同家族跨尺寸也跳 (Qwen3 6%/46%/69%/93%),
         不随规模单调, 不能用家族或尺寸预测.

   5.2 两种分布模式 (按 hidden.|max| 层间演化)
       模式 A: 突然跳变 + 中层保持 + 末层消退  (14/24, Sun 三段式)
         成员: Qwen2.5 / Qwen3 Dense / Ling / GPT-OSS
         特征: 早层 (L1-6) 单层 ≥10× 跳变 (实测 27×–230×),
               中层 plateau, 末层下掉.
         Ling 训练: 跳变强度 27→14→74→92× (非单调).

       模式 B: 渐进增长 + 末层不消退  (10/24)
         成员: Qwen3.5 (整家族), Gemma2 / Gemma3
         特征: 相邻层比 ≤6×, 激活值缓慢累积; 峰值贴末层
               (Gemma2-27b 末 3 层 206→237→307, 持续上升).
         子情形: Qwen3.5 绝对值最小 (122–1848, Sun 多不过);
                 Gemma 绝对值最大 (up to 696K).

       → 模式 A/B 与"家族"强相关: Qwen2.5/Qwen3/Ling → A;
         Qwen3.5/Gemma → B. 与规模无显著相关.

   5.3 载体分布 (与模式无关, 跨模式稳定)
       hidden 22/24, mlp_out 1/24 (GPT-OSS), final_ln 1/24 (Qwen3.5-0.8B).
       embedding 永远 <1.3. top1/top5_mean ≈ 1.01, decay5/1 ≈ 0.99
       — 支持 Sun "少 token × 少 dim" 在两种模式下都成立.
       Top5 多层传播: 23/24 模型 top5 分布于 ≥2 层
                      (唯一单层 Qwen3.5-0.8B, 同时 Sun 不过).


6. 规模效应 (|x*| 全局)
   Qwen2.5     1.5B→7B→32B   8.0K→13.2K→30.8K    3.9×  近似线性
   Qwen2.5-VL  3B→7B→32B     4.0K→8.3K→22.1K     5.5×  单调
   Qwen3       1.7B→8B→32B   14.2K→17.7K→35.3K   2.5×  亚线性
   Qwen3.5     0.8B→9B→27B   122→956→1848        15.1× 超线性(绝对值最小)
   Gemma2      2b→9b→27b     3.0K→1.7K→157.7K    92×   非线性(2→9B 反降)
   Gemma3      4b→27b        245.7K→696.3K       2.8×

   结论: Dense 大体单调; Gemma2 有尺寸低谷; Qwen3.5 增长比例最大但绝对值最小.


7. 跨架构对比 (聚焦量级与符号; 分布模式见 §5.2)
   核心结论: 家族间量级差距 ≈ 60 × 家族内差距, 载体是唯一跨家族不变量,
             符号倾向不是.

   7.1 量级: 家族 > 规模 (定量)
       同家族跨尺寸 |x*| 比: ≤ 6× (Qwen3.5 例外 15×).
       跨家族同尺寸 |x*| 比: 最高 380×.
         ~1–2B   Qwen3.5-0.8B 122   ↔ Qwen3-1.7B 14.2K     117×
         ~8–9B   Qwen3.5-9B 956    ↔ Qwen3-8B 17.7K         18×
         ~27–32B Qwen3.5-27B 1.8K  ↔ Gemma3-27b 696K       377×
                 Qwen3.5-27B 1.8K  ↔ Qwen2.5-32B 30.8K      17×
       → 量级由家族主导, 规模只做线性/亚线性缩放.

   7.2 载体: 跨家族唯一不变量
       hidden 22/24 (91.7%), 仅 GPT-OSS (mlp_out) / Qwen3.5-0.8B (final_ln) 例外.
       → 量化/部署可把 scale 策略统一绑定到残差流.

   7.3 符号倾向: 不是家族不变量
       家族级同号: Ling 4/4 负, Qwen3 4/4 正, Gemma3 2/2 正. (3/7 家族)
       混合家族: Qwen2.5 / VL / Qwen3.5 / Gemma2 均存在"某尺寸翻号".
       → 符号只是"常见倾向", 不能作为家族指纹.

   7.4 部署含义
       量化档按家族定 (见 §10.1), 同家族内规模变化基本落在同档;
       跨家族迁移量化方案不可靠 (380× 差距).


8. 代际演进
   Qwen2.5 → Qwen3 → Qwen3.5 (三个尺寸段):
       1.5–1.7B:  8.0K → 14.2K → 0.12K    先升后 100× 暴降
       7–9B:     13.2K → 17.7K → 0.96K    先升后 18× 暴降
       27–32B:   30.8K → 35.3K → 1.85K    先升后 19× 暴降
       Qwen3.5 跳变同时转 gradual, Sun 判据大多不过.

   Gemma2 → Gemma3:
       4–9B: 1.7K → 245.7K  (×145, 反向)
       27B:  157.7K → 696.3K (×4.4)
       注: Gemma3 只有 it, 存在 Base/Instruct 混淆 (见 §9.5).


9. 特殊架构
   9.1 MoE vs Dense
       Qwen3-30B-A3B / Qwen3-32B       1.5K / 35.3K = 4.3%
       Qwen3.5-35B-A3B / Qwen3.5-27B    132 / 1.85K = 7.1%
       → MoE 压 10–25×; Qwen3-30B-A3B 峰值 layer_3 (6%).

   9.2 Ling 训练 (5T/10T/15T/20T)
       |x*|: 7.6K → 9.0K → 10.1K → 11.8K  (+54%)
       跳变倍数: 27× → 14× → 74× → 92×  (非单调, 20T 最猛)
       峰值层: 14 → 10 → 19 → 19
       → 支持 Sun "隐式 bias 训练出来" 假设, 但单调性需加限定.

   9.3 VL vs Text (Qwen2.5)
       7B:  13.2K ↔ 8.3K  (VL 低 37%)
       32B: 30.8K ↔ 22.1K (VL 低 28%)
       注: 混淆见 §9.5, 32B 的差异与 SFT 贡献吻合.

   9.4 GPT-OSS-20B
       全局 max 落 mlp_out (|x*|=145K), top5 同号且数值几乎相等 (component-bias 型).

   9.5 Base vs Instruct (仅此节使用 3 个 Instruct; SFT = 监督微调, Base→Instruct)
       配对: Qwen2.5-{1.5B, 7B, 32B} × {Base, Instruct}

       逐层 hidden.|max| (B→IT):
         尺寸  中层(I/B)     末-1层           末层
         1.5B  L2-24 1.000   294 → 400        1536 → 840  (-45%)
         7B    L4-24 1.005   3216 → 3584      4864 → 2528 (-48%)
         32B   L6-60 1.006   15232 → 15488    30848 → 21248 (-31%)

       结论: SFT 只改末层 —— 中层 plateau 1:1 保留 (偏差 ≤1%),
             末层统一压缩 -31%~-48%, 末-1 层小幅补偿.
             载体/符号/top5/Sun 判据全部保留.
             32B "|x*| -28% + peak 63→42" 本质是末层被压下去后
             原本就存在的中层 plateau (L42=22144) 自然露出, 非结构重排.

       跨节校准: SFT 末层 ≤50% 是 Instruct 影响的上界.
                 §9.3 VL-32B -28% 与 SFT-32B -31% 重合 (Instruct 可解释);
                 VL-7B -37% 超 SFT-7B (存在 VL 机制);
                 §8 Gemma 代际 2.8×-145× >> 此上界 (代际真实).


10. Discussion
    10.1 量化分层 (|x*|)
         T1 (极佳)  Qwen3.5, MoE                   120 – 1.85K
         T2 (良好)  Gemma2 小模型, Qwen3-30B-A3B   1.5K – 3K
         T3 (中等)  Qwen2.5, VL, Qwen3 Dense        4K – 35K
         T4 (难)    Gemma2-27b, GPT-OSS            145K – 158K
         T5 (极难)  Gemma3                         246K – 696K
         T4/T5 建议 SmoothQuant 或混合精度.

    10.2 架构: MoE 天然抑制; Qwen3.5 同时抑制量级 + 改变跳变模式;
              Gemma3 比 Gemma2 更极端, 说明架构改进 ≠ 激活值改善.

    10.3 训练: Ling 表明训得越久 |x*| 越大, 但跳变强度非单调.

    10.4 vs Sun:
         - 一致: 普遍性 (20/24)、少数 token×dim、hidden 为主.
         - 新增: Qwen3.5 整家族 Sun 不过 / 跳变 gradual / 末层峰值;
                 代际反转 (Qwen -100× vs Gemma +145×);
                 MoE 系统性抑制; Ling 训练步数单调上升.

    10.5 局限:
         - Instruct 混淆 (VL, Gemma3) — Qwen2.5 对照见 §9.5, 上界 ~28%.
         - 单一评测集 (5000 样本)
         - 未做 intervention / causal 验证
         - per-element 分布未全盘存盘


11. Conclusion
    - 8 系列 / 24 checkpoint / 20 通过 Sun 判据
    - 量级跨度 5700× (122 vs 696K)
    - 四大因素: 架构 (MoE/Dense) · 代际 · 训练数据量 · 家族 normalization
    - 抑制方向: MoE (稀疏激活) / Qwen3.5 (架构内抑)
    - Gemma 代际反例: 架构改进不一定降激活
    - 下一步: feature dim 分析 · intervention · 更多训练 checkpoint
